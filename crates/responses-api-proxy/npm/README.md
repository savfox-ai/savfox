# @openai/savfox-responses-api-proxy

<p align="center"><code>npm i -g @openai/savfox-responses-api-proxy</code> to install <code>savfox-responses-api-proxy</code></p>

This package distributes the prebuilt [Savfox Responses API proxy binary](https://github.com/openai/savfox/tree/main/savfox-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/savfox-responses-api-proxy.js --help
```

Refer to [`savfox-rs/responses-api-proxy/README.md`](https://github.com/openai/savfox/blob/main/savfox-rs/responses-api-proxy/README.md) for detailed documentation.
