# Web Search

Search the web for information using search engines.

## Search Types

### General Search

```
Search for <query>
Look up <topic>
Find information about <subject>
What is <query>?
```

### News Search

```
Search news for <query>
Latest news about <topic>
Recent articles on <subject>
```

### Image Search

```
Find images of <query>
Search for pictures of <subject>
Show me images related to <topic>
```

### Video Search

```
Search for videos about <topic>
Find tutorials on <subject>
Look for <query> videos
```

## Search Operators

Use these to refine searches:

- `"exact phrase"` - Match exact phrase
- `site:domain.com` - Search within a site
- `-exclude` - Exclude terms
- `filetype:pdf` - Find specific file types
- `before:YYYY-MM-DD` - Results before date
- `after:YYYY-MM-DD` - Results after date

## Result Handling

### Provide

1. Direct answers when available
2. Relevant snippets from top results
3. Source URLs for verification
4. Multiple perspectives on controversial topics

### Avoid

1. Outdated information
2. Unreliable sources
3. Paid/promoted content without disclosure

## Best Practices

1. Verify information from multiple sources
2. Cite sources when providing facts
3. Note the date of information
4. Acknowledge uncertainty when results are ambiguous
5. Respect user privacy - don't log sensitive searches
