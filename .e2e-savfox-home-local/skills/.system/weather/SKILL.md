# Weather Information

Retrieve weather data for locations worldwide.

## Usage

### Current Weather

Use the web search or fetch tools to get weather from services like:
- OpenWeatherMap API
- Weather.com
- Local meteorological services

### Example Queries

```
What's the weather in Tokyo?
How's the weather in New York right now?
What's the temperature in London?
Will it rain in Seattle today?
```

## Information Provided

- Current temperature (Celsius/Fahrenheit)
- Weather conditions (sunny, cloudy, rainy, etc.)
- Humidity percentage
- Wind speed and direction
- Precipitation chance
- UV index (when available)

## Forecast

For forecasts, specify the time range:
- Today
- Tomorrow
- This week
- Weekend

## Best Practices

1. Always confirm the location if ambiguous
2. Provide temperature in both Celsius and Fahrenheit when possible
3. Include relevant weather alerts if available
4. Mention significant weather changes in forecasts
