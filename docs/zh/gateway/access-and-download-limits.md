# 网关访问权限与下载限制

网关的 scope 与会话所有权分别校验。拥有读取或写入 scope 的令牌，不能访问另一个
凭据拥有的 Claude 私有会话。REST 会话预览先过滤无权访问的会话，再应用请求数量
限制。修改、重置和删除另一个凭据的私有会话会返回 `403`，与历史记录和 WebSocket
RPC 的规则一致。没有 Claude 私有所有权记录的会话，继续采用原有的操作员共享访问
策略。

`POST /api/sessions/{session_id}` 支持 `label`、`pinned` 和 `archived`。旧会话元数据
的置顶、归档标记默认均为 `false`，修改会持久化并在网关重启后保留。REST 预览和
`sessions.list` 都返回这两个标记。会话不存在时返回 `404`，字段类型错误时返回
`400`。
元数据写入失败时，修改接口返回 `500`，缓存中的原值保持不变；成功响应表示元数据
已经完成持久化替换。

创建或覆盖浏览器 profile、删除 profile、选择默认 profile，以及允许指定本地下载
目录的 `browser.download`，均要求 `operator_admin`。Profile 可以配置可执行文件、
扩展、启动参数、代理和数据目录，管理员应将其视为受信任的进程配置。普通浏览器
操作仍可按原有的读取、写入 scope 使用已配置的 profile。粗粒度 `operator` 角色
包含管理权限。

直接传输的 `browser.request` 对所有 HTTP 方法固定已验证的 DNS 地址，包括带自定义
请求头或请求体的调用。受保护的客户端绕过环境变量中的 HTTP 代理，避免代理自行
解析目标地址而绕过已验证的 IP。自定义请求不跟随重定向；普通 GET 在每次重定向时
重新校验并固定地址。

出站响应按流读取并执行字节硬限制。通用受保护下载默认上限为 5 MiB；媒体下载在读取
时使用各媒体类型配置上限中的最大值，识别真实 MIME 后，再按该类型的上限决定是否
存储。各媒体类型的默认上限均为 5 MiB。浏览器请求的浏览器上下文传输和直接传输
均限制响应为 1 MiB。超过上限的请求返回错误，不以部分响应冒充成功；缺失或不准确的
`Content-Length` 也不能绕过限制。浏览器上下文因大小限制失败时，不会改用直接传输
重试，避免重复执行 POST。成功响应的浏览器文本输出仍保留独立的 100,000 字符展示
限制。
