# 向量记忆检索

检索结果摘要在 700 字节以内保留完整的 UTF-8 字符，再追加省略号。较长的中文或 emoji 内容不会因截断导致检索崩溃。

## 向量记忆索引同步

记忆与会话文件按来源、路径和内容哈希跟踪。未变化的文件跳过 embedding；变化文件先完成所有新向量计算，再用同一事务替换旧分块和向量。空文件同样记录。完整成功扫描会清理已删除文件的索引，同时保留手动记忆。读取或 embedding 失败会保留上次发布的文件版本。旧索引首次同步时逐文件重建，以清除历史重复版本。

## 向量检索资源使用

精确向量检索在阻塞工作线程中流式读取 ID 和向量，只用有界堆保留最佳 k 个候选，最后在同一数据库快照中读取获选条目的完整正文。分数降序排列，同分按插入顺序，未定义分数排在最后。结果上限为零时不扫描。算法仍需计算每个已存向量，CPU 开销随索引大小与维度线性增长；候选保留内存为 O(k)，加上数据库的有界行缓冲。

## QMD 文档往返保存

`.qmd` 存储只把完整的 `---` 行识别为 YAML 元数据分隔线，支持 LF 和 CRLF，闭合行也可以位于文件末尾。读取文档或只更新元数据时，正文的空白、换行和 Markdown 分隔线保持不变，不会累积空行。没有起始分隔线的文档完整保留为普通正文，`---word` 不会被当作分隔线；存在起始行却没有完整闭合行时，返回元数据缺失错误。
